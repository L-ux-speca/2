# Спрайты Tokyo Dawn

Здесь можно хранить оригинальные PNG/WebP-кадры персонажей. Игра их **не пережимает** и не изменяет на диске: браузер только отображает исходный файл.

## Пример: спрайты Ляписа

1. Создай `assets/sprites/lapis/`.
2. Добавь туда прозрачные изображения `idle-1.png`, `idle-2.png`, `walk-1.png` и т. д.
3. Открой `src/data/sprites.js` и добавь объект:

```javascript
const SPRITE_MANIFEST = {
  lapis: {
    displayHeight: 104,
    states: {
      idle: { paths: ['assets/sprites/lapis/idle-1.png',
                     'assets/sprites/lapis/idle-2.png'], fps: 4 },
      walk: { paths: ['assets/sprites/lapis/walk-1.png'], fps: 9 }
    }
  }
};
```

Это пример: перед добавлением удали существующее пустое объявление `const SPRITE_MANIFEST = {};`.

Поддерживаются состояния: `idle`, `walk`, `run`, `jump`, `crouch`, `block`, `hit`, `punch`, `kick`, `throw`, `skill`, `ko`.

Можно указать один горизонтальный **спрайт-лист** вместо отдельных изображений:

```javascript
walk: {
  src: 'assets/sprites/lapis/walk.png',
  frameWidth: 96,
  frameHeight: 144,
  frames: 8,
  fps: 12,
  loop: true
}
```

Все кадры одного состояния должны иметь **одинаковый размер холста и положение ног**, даже если части спрайта не занимают всю площадь. У персонажа точка привязки — середина ступней, игровая ширина и высота хитбокса от изображения **не зависят**. Слева и справа используется зеркальное отражение одного набора кадров.

Можно настроить `displayHeight`, `scale`, `offsetX` и `offsetY` для каждой анимации без изменения исходной картинки.

Если нужного файла нет или изображение ещё не загрузилось, игра показывает предыдущую векторную модель; бой продолжается.
