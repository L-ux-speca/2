# Фоны арен

Размещай здесь новые оригинальные изображения фонов (`.png`, `.jpg`, `.webp`). Описания новых арен добавляются в `src/data/custom-content.js` через `ArenaCatalog.register(...)`.

Параметры: `id`, `name`, `camera: 'fixed' | 'follow'`, `colors`, `floor`, `background`.

- **fixed**: камера не перемещается, бой ограничен границами арены. Рекомендуется для обычного файтинга.
- **follow**: камера следит за бойцами и позволяет уходить за пределы обычного экрана. Используй только для действительно больших арен.

Фоновое изображение выводится с сохранением пропорций; лишняя часть по краям может быть обрезана. Сам файл не пережимается и не редактируется.
