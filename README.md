# Tokyo Dawn — браузерный файтинг

Версия **2.3.0**. Проект по-прежнему использует HTML5 Canvas и JavaScript, но исходники больше не собраны в один огромный HTML-файл. Сохранены 14 бойцов, 5 арен, РТ Араи, конструктор приёмов, локальный бой, тренировка, онлайн-режим и оригинальные портреты.

## Публикация на GitHub Pages

1. Распакуй исходный ZIP.
2. Перенеси **всё содержимое папки проекта** в корень репозитория GitHub: `index.html`, `styles/`, `src/`, `assets/` (для тестов и отдельной сборки также `tests/`, `tools/`, `package.json`).
3. Если `assets/portraits/` уже есть с теми же именами файлов, повторно загружать неизменённые портреты не нужно.
4. Настрой GitHub Pages на ветку `main`, папку `/ (root)`.
5. После публикации обнови страницу с очисткой кеша.

**Важно:** теперь одного `index.html` недостаточно — ему необходимы файлы из `src/` и `styles/`. Портреты загружаются из `assets/portraits/` без пересжатия.

Для безопасного переноса используются **обычные JavaScript-файлы с последовательным подключением**. Это модульное разделение исходников по ответственности, но пока не переход на синтаксис ES Modules (`import`/`export`). Такой выбор сохраняет совместимость с оригинальным кодом и GitHub Pages. При следующих больших изменениях можно постепенно выделять настоящие ES-модули.

## Третий приём Ляписа

«Притяжение» за **10 ПЭ** выпускает вперёд магнитный снаряд-якорь со скоростью **480 пикселей/с**. Он летит **4 секунды**, не наносит урон и не останавливается от столкновения с противником. На обычных аренах останавливается у границы, не покидая поле боя. Пока якорь существует, двойное нажатие влево или вправо переносит Ляписа к **текущему** положению снаряда и расходует якорь. В режиме РТ Араи навык пока сохраняет отдельную адаптированную механику магнитного поля.

## Проверка и сборка

Не требуется установка внешних зависимостей, достаточно Node.js:

```sh
npm test
npm run build:standalone
```

Первая команда проверяет механику боя, способности всех персонажей, исходные портреты и новое разделение по файлам. Вторая создаёт `Tokyo_Dawn_Standalone.html` рядом с папкой проекта: в этот отдельный файл встроены JS, CSS и портреты (сами байты изображений не изменяются).

Для обычных обновлений GitHub Pages лучше использовать **многофайловый проект**, чтобы редактировать небольшие файлы прямо на GitHub. Самостоятельный HTML предназначен для быстрой передачи и локального запуска.
